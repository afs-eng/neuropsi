# Skills GoPsi — interpretação por instrumento

Oito especialistas extraídos dos instrumentos presentes no laudo de Guilherme Cabral Costa. **BPA-2 não incluído.**

## Integração sugerida
1. Backend calcula escores, classificações e dados normativos.
2. Coordenador seleciona `gopsi_skills/<instrumento>/SKILL.md`.
3. Especialista recebe somente dados daquele teste e contexto clínico relevante.
4. Validador confere JSON, fatos, classificações e ausência de percentis no texto.
5. Coordenador integra os textos sem duplicar conclusões e mantém diagnóstico para síntese clínica final.

O conteúdo é uma especificação de prompts/skills, não substitui os manuais nem validação profissional.
