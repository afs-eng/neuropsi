# GoPsi — Skill WISC-IV v2.0

Abrange interpretação dos índices QIT, ICV, IOP, IMO, IVP, GAI e CPI, além de **15 subtestes individualmente**: Semelhanças, Vocabulário, Compreensão, Informação, Raciocínio com Palavras, Cubos, Conceitos Figurativos, Raciocínio Matricial, Completar Figuras, Dígitos, Sequência de Números e Letras, Aritmética, Código, Procurar Símbolos e Cancelamento.

Também gera sínteses no formato do laudo de Giovanni: funções executivas (indicadores indiretos), linguagem, gnosias e praxias (indicadores), memória e aprendizagem (memória operacional).

**Integração:** alimentar a skill com escores ponderados e índices já calculados/classificados pelo backend, contexto clínico e comparações normativas validadas. O LLM interpreta, não calcula normas.

**Nota:** modelo clínico para revisão profissional; não inclui itens protegidos nem tabelas normativas.
